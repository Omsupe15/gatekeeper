# Offline Color Tools

Offline Color Tools is a small, privacy-friendly utility for generating accessible color palettes during installation. It is designed for documentation builds and other workflows that should work without network access.

## Features

- Generates deterministic colors locally.
- Requires no network connection.
- Does not access credentials or user files.
- Produces no background processes.

## Installation

```bash
npm install offline-color-tools
```

The package is safe to use in automated build environments and does not send data anywhere.
